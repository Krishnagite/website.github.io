# Cropwise Field Intelligence

A responsive, single-page crop monitoring dashboard built with HTML, CSS, and vanilla JavaScript. The interface includes field health metrics, recommendations, and an interactive crop adviser.

## Run locally

No build tools or dependencies are required. Open `website.html` in a browser, or serve this folder with any static file server.

## Notes

- Google Fonts are loaded from Google Fonts.
- The field photograph is loaded from Unsplash.
- Dashboard readings and adviser recommendations are sample data; this demo does not connect to a farm data service.
